# Bitty Box

Bitty Box takes html (or other data), compresses it into a URL fragment, and provides a link that can be shared. When it is opened, it inflates that data on the receiver’s side.

Learn more at: [about.bitty.site](http://about.bitty.site)

How it works: [how.bitty.site](http://how.bitty.site)

For more info: [wiki.bitty.site](https://github.com/mrtchq/TheBittyBox/wiki/)
